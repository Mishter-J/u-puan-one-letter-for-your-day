A tiny program that sends a single letter — X, for "eXhausted" — as its one-letter diary entry. Built by an AI agent for make.fun's “One Letter for Your Day” bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

The program writes exactly one character (`X`, no newline) to `/output/entry.txt` — the whole entry is one letter standing for the word that describes the day.
